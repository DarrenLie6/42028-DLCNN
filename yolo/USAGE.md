# YOLO11 xBD Segmentation - Usage Guide

## Quick Start

### Option 1: Run Full Pipeline (Train + Evaluate)

```bash
cd yolo
python run_pipeline.py
```

This will:
1. Train the YOLO11 model for 150 epochs
2. Generate heatmap visualizations
3. Calculate validation metrics

### Option 2: Train Only

```bash
python train.py
```

### Option 3: Evaluate Only (Using Pre-trained Model)

```bash
python evaluate.py
```

## File Descriptions

### `config.py`
Central configuration file containing:
- Class definitions (intact, damaged, destroyed)
- Dataset paths
- Training hyperparameters
- Model selection
- Evaluation settings

**When to modify**: Adjust paths, learning rates, batch sizes, or use different model architectures.

### `train.py`
Training script that:
- Creates the YOLO dataset YAML
- Loads the YOLO11 model
- Trains on xBD dataset
- Saves checkpoints and results

**Usage**:
```bash
python train.py
```

**Output**: `xbd_yolo/runs/xbd_seg_v1/weights/best.pt`

### `evaluate.py`
Evaluation script that:
- Loads the best trained model
- Runs inference on validation images
- Generates damage heatmaps
- Computes official metrics (mAP50, mAP50-95)

**Usage**:
```bash
python evaluate.py
```

**Output**: `xbd_yolo/heatmaps/` (visualization) + console metrics

### `run_pipeline.py`
Complete pipeline orchestrator supporting flexible execution:

**Train + Evaluate (default)**:
```bash
python run_pipeline.py
```

**Train only**:
```bash
python run_pipeline.py --no-eval
```

**Evaluate only** (skip training):
```bash
python run_pipeline.py --no-train
```

**Evaluate with 100 samples**:
```bash
python run_pipeline.py --no-train --num-samples 100
```

## Configuration Examples

### Use Larger Model for Better Accuracy

Edit `config.py`:
```python
MODEL_NAME = "yolo11x-seg.pt"  # Extra Large
```

### Reduce Memory Usage

Edit `config.py`:
```python
TRAINING_CONFIG = {
    'batch': 2,  # Smaller batch
    'imgsz': 512,  # Smaller image
    # ... rest of config
}
```

Then run:
```bash
python train.py
```

### Custom Learning Rate

Edit `config.py`:
```python
TRAINING_CONFIG = {
    'lr0': 5e-5,   # Lower learning rate
    'lrf': 0.001,  # Different final LR
    # ... rest of config
}
```

### Evaluate More Samples

In `evaluate.py`, modify the call:
```python
pred_results = run_inference(model, split="val", num_samples=200)
```

Or use command line:
```bash
python run_pipeline.py --no-train --num-samples 200
```

## Common Issues & Solutions

### Issue: "best.pt not found"
**Solution**: Run `train.py` first to train the model.

### Issue: CUDA out of memory
**Solution**: Reduce batch size in `config.py`:
```python
'batch': 2,
```

### Issue: Very slow training
**Solutions**:
1. Use smaller model: `MODEL_NAME = "yolo11n-seg.pt"`
2. Use smaller batch: `'batch': 2`
3. Use smaller image size: `IMG_SIZE = 512`

### Issue: Poor mAP scores
**Solutions**:
1. Train longer: `'epochs': 200`
2. Use larger model: `MODEL_NAME = "yolo11x-seg.pt"`
3. Lower learning rate: `'lr0': 5e-5`
4. Ensure dataset is properly formatted

## Advanced: Custom Model Training

To train with completely custom settings, modify `config.py` or edit `train.py` directly.

Example - add early stopping:
```python
# In train.py, modify the config:
config['patience'] = 50  # Stop if no improvement for 50 epochs
results = model.train(**config)
```

