HOW TO USE:

Just run:
  python train.py

The script automatically:
  1. Checks if checkpoint exists (best.pt or last.pt)
  2. If found → Loads checkpoint and resumes
  3. If not found → Starts fresh from pretrained weights

KEY FEATURES:

🎯 Automatic Detection
   • No manual file selection needed
   • Script finds checkpoint automatically

🎯 Smart Selection
   • prefer_best=True → Uses best.pt (highest mAP)
   • prefer_best=False → Uses last.pt (latest epoch)
   • Falls back gracefully if preferred not found

🎯 Graceful Handling
   • best.pt not found → Falls back to last.pt
   • last.pt not found → Starts fresh
   • No crashes or errors

🎯 Seamless Continuation
   • Preserves all optimizer state
   • Continues from next epoch
   • Updates results seamlessly

═══════════════════════════════════════════════════════════════════════════════

CONFIGURATION OPTIONS:

Default (Recommended):
  resume=True, prefer_best=True
  → Resume from best.pt if available
  → Fall back to last.pt
  → Start fresh if neither exists

Alternative 1:
  resume=True, prefer_best=False
  → Resume from last.pt if available
  → Fall back to best.pt
  → Start fresh if neither exists

Alternative 2:
  resume=False
  → Always start fresh
  → Ignore all checkpoints
