Edit config.py to change:

1. Use Larger Model (better accuracy, slower):
   MODEL_NAME = "yolo11x-seg.pt"

2. Smaller Batch (save memory):
   TRAINING_CONFIG['batch'] = 2

3. Different Learning Rate:
   TRAINING_CONFIG['lr0'] = 5e-5

4. More Training Epochs:
   TRAINING_CONFIG['epochs'] = 200

5. Custom Dataset Path:
   YOLO_DS_DIR = r"C:\path\to\dataset"

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"best.pt not found"
  → Run train.py first to train the model

GPU Out of Memory (OOM)
  → Reduce batch size: TRAINING_CONFIG['batch'] = 2

No GPU Available
  → Set in config.py: 'device': 'cpu'

Very Slow Training
  → Use smaller model: MODEL_NAME = "yolo11n-seg.pt"
