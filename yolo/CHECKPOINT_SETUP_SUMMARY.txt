RESUME FROM CHECKPOINT:

If training is interrupted, resume from the last checkpoint:

   # In Python:
   from ultralytics import YOLO
   model = YOLO('xbd_yolo/runs/xbd_seg_v1/weights/last.pt')
   model.train(data='xbd_yolo/xbd.yaml', epochs=200, resume=True)

   # Or use a specific epoch:
   model = YOLO('xbd_yolo/runs/xbd_seg_v1/weights/epoch50.pt')

STORAGE NOTE:

Each checkpoint is ~650 MB (for yolo11l-seg)
150 epochs × 650 MB ≈ 97.5 GB total

To save space, you can:
1. Change save_period to 5 (saves every 5 epochs)
2. Delete old checkpoints after training
3. Keep only best.pt for inference
