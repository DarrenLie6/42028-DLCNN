WHAT HAPPENS NOW WHEN YOU RUN: python train.py

1. 📊 Console Output:
   Shows training configuration including:
   • "Checkpoints: Saved every epoch"
   • "Training Curves: Updated each epoch"
   • Results location
   
2. 💾 After Each Epoch:
   Saves: weights/epoch{N}.pt
   Example:
   • Epoch 1 → weights/epoch1.pt
   • Epoch 2 → weights/epoch2.pt
   • ...
   • Epoch 150 → weights/epoch150.pt
   
3. 📈 After Each Epoch:
   Updates: results.png with training curves
   Shows 8 plots:
   • box_loss, seg_loss, cls_loss, dfl_loss
   • Precision, recall, val_box_loss, val_seg_loss
   
4. 📋 After Each Epoch:
   Updates: results.csv with metrics
   Contains: epoch, losses, mAP, etc.
   
5. 🏆 Best Model:
   Saves: weights/best.pt
   Auto-updated when validation improves

USAGE EXAMPLES:

1. Train & Save All Checkpoints:
   python train.py

2. Resume from Last Checkpoint (if interrupted):
   from ultralytics import YOLO
   model = YOLO('xbd_yolo/runs/xbd_seg_v1/weights/last.pt')
   model.train(data='xbd_yolo/xbd.yaml', epochs=200, resume=True)

3. Load Specific Epoch Checkpoint:
   from ultralytics import YOLO
   model = YOLO('xbd_yolo/runs/xbd_seg_v1/weights/epoch50.pt')
   results = model.predict('image.jpg')

4. Reduce Storage (Save Every 5 Epochs):
   Edit config.py:
   TRAINING_CONFIG['save_period'] = 5
