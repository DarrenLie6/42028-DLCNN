WHAT'S NEW:

✨ Automatic Checkpoint Detection
   └─ Detects best.pt or last.pt automatically
   └─ No manual intervention needed

✨ Smart Resume Logic
   └─ Prefers best model or latest (configurable)
   └─ Falls back gracefully if checkpoint not found
   └─ Starts fresh if no checkpoint exists

✨ Seamless Training Continuation
   └─ Resumes from exact checkpoint
   └─ Preserves all training state
   └─ Continues to next epoch

═══════════════════════════════════════════════════════════════════════════

HOW TO USE:

1. First Time Training:
   $ python train.py
   → Starts from epoch 1
   
2. If Training Interrupted:
   $ python train.py
   → Automatically detects checkpoint
   → Resumes from checkpoint
   → Continues remaining epochs

3. No Configuration Needed!
   → All handled automatically
   → Default config is optimal

═══════════════════════════════════════════════════════════════════════════

CONFIGURATIONS:

Default (Recommended):
  RESUME_CONFIG = {
      'resume': True,              # Auto-resume enabled ✅
      'prefer_best': True,         # Use best.pt ✅
  }

Alternative 1 (Resume Latest):
  RESUME_CONFIG = {
      'resume': True,
      'prefer_best': False,        # Use last.pt instead
  }

Alternative 2 (Always Fresh):
  RESUME_CONFIG = {
      'resume': False,             # Disable auto-resume
      'prefer_best': True,
  }

═══════════════════════════════════════════════════════════════════════════

BEHAVIOR:

resume=True, prefer_best=True (Default)
├─ Tries: best.pt
├─ Falls back to: last.pt
└─ If neither exists: Start fresh

resume=True, prefer_best=False
├─ Tries: last.pt
├─ Falls back to: best.pt
└─ If neither exists: Start fresh

resume=False
└─ Always start fresh, ignore checkpoints

═══════════════════════════════════════════════════════════════════════════

WHICH CHECKPOINT IS USED:

best.pt  ← Best validation performance
         ← Useful when optimization is plateauing
         ← Resume to get highest mAP

last.pt  ← Most recent training state
         ← Useful for immediate resume
         ← Maintains exact training momentum

═══════════════════════════════════════════════════════════════════════════

STORAGE:

Checkpoints saved:
  weights/best.pt          (updated when validation improves)
  weights/last.pt          (updated each epoch)
  weights/epoch1.pt        (after epoch 1)
  weights/epoch2.pt        (after epoch 2)
  ...
  weights/epoch150.pt      (after epoch 150)

Size per checkpoint: ~650 MB (yolo11l-seg)
Total for 150 epochs: ~97.5 GB
